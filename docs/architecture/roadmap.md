更新日期：2026-10-03。本文记录当前开发目标及分阶段实现情况。各阶段实际通过项以 [验证记录](../development/validation.md) 为准。

| 阶段 | 范围 | 当前状态 |
| --- | --- | --- |
| M0 | 桌面基础、扫描适配、本机连接边界 | 基础已实现，浏览器与跨平台实机验收待补 |
| M1 | A4 选择题模板、打印、导入与扫描采集 | 主要功能已实现，打印比例与部分 UI/设备验收待补 |

新增目标扩展模板和批阅能力，不把现有 M0–M4 的未验收项标为完成。macOS/Linux 实机及三平台 CI 继续按当前安排暂缓。

用户已确定先解决 M4 打包阻塞，再推进主观题。当前该阻塞已解除；M5 的版式相关实现仍需用户补充模板样式和生成方式。

## 新增目标与实施顺序

### 模板设计调整：先收集细节

用户将后续提供答题纸样式和生成方式的细节，目前不锁定具体版式、编辑方式、渲染格式或新增组件库。主观题区域需要纳入同一模板设计，避免先实现一套随后需要重做的生成器。

下一步设计需要明确：选择题与主观题如何混排、题号和分值、书写区域类型与尺寸，以及是否需要多页、跨页作答和页面/考生关联。后几项是待决定范围，不代表已承诺实现。

模板的数据描述与打印渲染应表达同一份布局；定位标记、题目区域和模板身份随最终设计一起调整。视觉样式和人工批阅流程的具体 UI 在设计确认后实施。

### M5：主观题扫描与人工批阅（分阶段推进）

目标：答题纸包含主观题书写区域，扫描后能按题查看作答图像并人工评分。

计划内容：

1. 模板记录主观题 ID、题号、满分、所在页及答题区域几何；与选择题共同生成答题纸。
2. 复用扫描和图像导入流程，保留完整原图。通过页面定位变换提取各题答题区域，保存区域与原图的对应关系；定位失败时明确要求重扫或人工处理，不把错误裁剪当作有效答案。
3. 本地批阅展示原图/题目区域，支持人工输入分数和评语、修改与确认；校验分值范围，并记录修订历史。
4. 区分未批阅、草稿和已确认，主观题尚未批完时不把总成绩标为最终结果。选择题、主观题和总分分别保留。
5. 人工评分及必要批阅记录保存在本地，明确重启后的恢复规则；不沿用当前仅内存业务索引作为长期批阅存储。
6. 本机服务与无 UI SDK 提供受控的答题区域访问、批阅提交、版本冲突检查、状态与结果导出。继续使用授权隔离和资源 ID，不向网站开放任意文件路径。

验收：混合题型模板能完成生成、打印/采集、区域定位、人工批阅、重新打开和结果导出；覆盖区域缺失、定位失败、未批阅、超分值、并发修改和跨授权访问。模板版式依赖上述设计细节确认。

已先接入 [M5-A 批阅基础](m5.md)：原图整数像素区域、受鉴权 PNG 读取、未批阅/草稿/已确认状态、整批评分与版本冲突、严格审计重放、本地原子保存和 JSON/CSV 导出。网页新授权不自动继承旧记录，未全部确认时不产生最终主观题小计。此阶段不修改已有选择题模板；混合模板、自动定位、多页关联、正式批阅界面和综合成绩仍待后续实现。

### M6：可选 OCR 与 AI 辅助批阅（新增计划）

目标：在人工批阅基础上，按需识别主观题内容并生成评分建议。OCR 与 AI 评分是独立步骤；人工批阅不依赖它们。

计划内容：

1. OCR 接收主观题区域图像，返回识别文本及可用的位置/质量信息，允许对照原图修正。手写、公式、图表等支持范围需用实际样本验收，不预设模型都能处理。
2. GLM-OCR 是用户提出的候选，暂不锁定库、模型版本、运行方式或许可结论。接入前核对官方能力、依赖、许可、模型体积、硬件要求与离线可用性；下载或新增依赖另行确认。
3. AI 批阅结合题目、满分、参考答案和评分细则，输出结构化的建议分数、分项依据、评语及待复核原因。依据引用可核对的作答内容，不以模型自报置信度证明准确率。
4. 默认先形成待人工确认的评分建议；若后续需要自动确认成绩，再单独确定适用题型、规则和验收标准。记录 OCR 修订、评分细则版本、模型版本及人工采纳/修改历史。
5. OCR/AI 运行由本地应用或本地适配器协调，TypeScript SDK 仍只负责连接与调用，不承载模型和 UI。先评估本地运行；若考虑云端，须另行明确外传内容、凭据、费用与授权，不自动上传作答图像或成绩。
6. 模型缺失、识别失败、取消、超时或无有效评分细则时返回明确状态，保留人工处理入口。批处理与重试不得静默重复计费或覆盖已确认成绩。

验收：用人工标注的作答样本分别评价 OCR 可读性和 AI 评分一致性，核对错误与待复核处理；模型输出属于建议的状态必须贯穿 UI、SDK 和导出。自动评分验收与模型下载尚未开始。

## 对已有模块的影响

| 模块 | 后续扩展 |
| --- | --- |
| Core | 混合题型、区域几何、主观题分值与综合成绩状态；保持平台无关 |
| Platform / Desktop | 区域图像提取与查看、人工批阅、本地存储、可选模型运行适配 |
| Protocol / Server | 区域资源、批阅任务与状态、版本控制、授权隔离及受控图像响应 |
| TypeScript SDK | 主观题资源、人工评分、OCR/AI 任务与结果的准确类型；保持无 UI |
| 模板生成与打印 | 按用户后续提供的样式和生成方式统一调整 |

M5-A 新增独立的批阅契约与存储，不改写已有真实采集记录或选择题模板 schema。后续版式实施仍先确定设计细节；尚未发布的开发中间版本不需要保留无用兼容层。
