# M5：主观题人工批阅

## 范围与分阶段交付

M5 的完整目标是混合题型答题纸生成、采集、按题查看、人工批阅与结果导出。模板样式和生成方式等待用户补充，暂不调整现有选择题模板 schema。

M5-A 最初实现人工指定像素区域的批阅基础，M5-B 加入本地批阅页面。用户随后明确区域定义属于答题纸生成流程，因此 M5-C 将题号、满分和纸面毫米区域纳入模板，批阅创建仅引用采集记录。以下像素坐标仍用于已有评分记录及内部图像映射，不再作为新建批阅的用户输入。多页、综合成绩及 OCR/AI 尚未接入。

## 区域与评分

生成时的区域使用纸面毫米坐标，批阅题号和满分来自采集所保存的模板。内部映射以存储原图左上角为原点，包含原图四角及校正题图尺寸；四边形外接像素矩形只用于边界与旧评分结构，不作为新题图的裁剪方式。不能将毫米模板坐标或预览缩放后的坐标直接当成原图像素。

每个批阅文档关联一条采集记录，包含 1–64 道主观题。题目 ID 和题号各自唯一，满分大于 0 且不超过 1,000,000。评分使用本地十进制数，必须在零分到满分之间。

每题有三种状态：未批阅、草稿、已确认。先保存草稿，再确认其中的分数和评语；修改已确认题目的分数或评语，要显式退回草稿。尚未全部确认时，最终主观题小计为空。此阶段不把主观题小计与现有选择题结果合并为整张答题纸总分。

提交包含预期版本和整批编辑；任一编辑无效，整批不生效。服务器记录批阅者、时间及修改前后内容，成功提交才递增版本。评语最多 256 字符，批阅者标识最多 64 字符，历史最多 128 次提交；达到限制时明确报错，不截断历史。持久化文件和任务返回的批阅文档分别限制为 384KiB，超限在保存前拒绝，避免已保存的评分被误报为失败。JSON/CSV 导出的外层响应仍受现有 1MiB 任务结果上限约束。

## 本机服务与 SDK

新增任务操作：

| 操作 | 用途 |
| --- | --- |
| `subjectiveCreate` | 从当前授权采集所保存的模板与页面定位创建批阅文档，仅接收 `captureId` |
| `subjectiveRead` | 读取当前授权的批阅文档与版本 |
| `subjectiveGrade` | 按预期版本原子提交人工评分 |
| `subjectiveExport` | 导出 JSON 或 CSV |

题目区域图片通过 `GET /v1/subjective-reviews/{reviewId}/questions/{questionId}/image` 获取，复用来源、凭据和授权检查。只接受资源 ID，不接受网站传入的本地文件路径或临时裁剪坐标。新模板题区经四角透视校正输出为 PNG，旧像素题区文档仍按保存的矩形读取；均不修改原图。单区域最多 4Mpx，输出最多 8MiB，超过限制明确返回错误，不自动缩放。响应禁止缓存，授权撤销后不得交付图像。

SDK 只提供类型与连接调用，不承担裁剪、评分、存储或 UI。批阅任务沿用现有幂等键和任务查询流程；版本冲突要求调用方重新读取并核对，不能自动覆盖他人的修改。

## 持久化与授权边界

批阅文档原子保存到应用私有数据目录，不保存访问 Token。文件是批阅状态的来源；同一数据目录的版本检查与保存串行执行，写成功后才返回新版本。读取持久化文档时验证区域、状态与历史，不直接信任文件中的最终分数。

网页只能访问当前授权创建的批阅文档及对应采集记录。相同网站重新配对取得的新授权不自动继承旧记录。应用重启后，可信本地入口可以读取已保存的批阅文档；不通过网站任意枚举旧记录，显式分享流程尚未实现。

导出保留各题状态、分数和最终主观题小计。JSON 包含历史；CSV 使用转义并防止单元格内容被作为公式执行。

## M5-B：本地批阅与重新打开

现有 NavigationView 中加入“主观题批阅”页，沿用现有 TitleBar 和页面风格。用户可以选择已保存的采集记录、预览原图、逐题保存草稿、确认、重置和导出；记录列表支持分页及重新打开。M5-B 最初提供的手工像素区域表单在 M5-C 移除，区域定义改到模板页。

可信本地入口可以读取以前由网页授权创建的批阅文档，编辑时保留原授权归属。本地新建文档使用保留的本地归属标记；网页授权 ID 由服务端生成，不能指定或继承该标记。新配对授权仍不自动获得旧记录。

本地与网页评分都经过存储层的版本事务：在同一进程、同一数据目录的共享写锁内读取、检查预期版本、应用编辑和原子替换。并发编辑同一版本只允许一次成功；保存失败或提交前取消时保留旧记录。文件列表只接受有界页大小与受控游标，不接受目录或文件路径；按资源 ID 排序，不表示时间先后。每页最多检查 50 条候选，损坏记录也占用额度并返回诊断；有后续记录时仍提供续页游标。

页面异步加载历史和图像，选择变化或离开页面后不显示过时图像。窗口关闭等待未结束操作。验证使用临时合成记录；默认用户目录不会被本轮自动测试枚举，真实桌面交互仍需要单独验收。

## M5-C：生成时定义区域

区域定义属于答题纸生成流程。模板页以纸面毫米坐标定义主观题题号、满分与书写区域；预览、SVG 与打印使用同一模板布局。批阅页只选择采集记录、创建或重新打开批阅文档，不再要求填写原图像素区域。

本阶段沿用单页 A4、现有选择题几何和定位标记，仅在空白处增加主观题区域，验证页内边界与内容重叠。不提前锁定后续纸面视觉样式、拖拽编辑或多页范围。区域定义参与模板身份；新采集保存对应模板快照，不能用当前界面模板替代历史答卷的定义。

采集关联使用用户或 SDK 选择的模板，本阶段不自动识别纸面模板编号；采集时仍需选择与实际答题纸一致的模板。

批阅创建复用页面定位与方向判定，把模板区域映射为原图四边形并校正为题图。缺少主观题模板或定位失败时明确拒绝，保留原图；不按图像尺寸比例猜测，也不使用四边形外接矩形冒充校正题图。旧采集和已有像素区域评分文档保持读取路径，不删除或重写用户数据。

尚未发布的 `subjectiveCreate` 接口调整为只接收 `captureId`，区域、题号和满分取自该采集的模板。Core、裁图像素、本地/网页业务回归、SDK 实际回环及 Windows/Uno 构建已通过，实际命令与限制见验证文档。

## 验证与剩余验收

代码级验证覆盖区域边界、分值、批阅状态、版本冲突、整批原子性、历史恢复、持久化、授权隔离、区域裁剪及 SDK 类型与调用。使用合成图像和临时目录，不访问真实采集数据或扫描设备。实际通过项记录在 [验证记录](../development/validation.md)。

M5 完整验收仍需后续模板设计细节、真实纸张打印与采集、真实样本定位和综合成绩验证。模板区域、自动题图提取、本地批阅与重新打开已有代码及合成回归，真实界面操作、系统缩放与窄窗口仍待验收。OCR 与 AI 辅助批阅属于 M6，模型与运行方式尚未选定。
