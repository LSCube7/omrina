# OMRINA UI/UX 与答题纸设计约定

更新日期：2026-10-03。

本文归档本轮界面与答题纸讨论，以用户最后一次修正为准。**这是后续设计与开发依据，不表示功能已经实现。** 当前仅保存文档，不修改程序。

## 1. 产品与实现边界

- 保持本地引擎、桌面应用与无 UI TypeScript SDK 的现有分工；模板、采集、识别、批阅、任务和结果在本地处理，SDK 提供调用能力。
- Windows 继续使用 WinUI 3；保留 Uno 的平台边界，不新增 Web UI，不在本轮更换技术栈或引入组件库。
- 根目录 `design.png` 暂不提取或加入程序，继续预留品牌 LOGO 位置。
- 聊天中的纸面预览只是结构草案，非 1:1 打印文件。考试码与考号条码都是占位示意，尚不可解码。
- 已有单页 A4 能力、当前批阅功能与本轮设计要求应分开描述；A3、多栏、多页身份关联和新的生成方式需要后续实现与验收。

## 2. 已确认的界面要求

### 2.1 用户流程

当前软件的用户逻辑需要梳理，避免用户自行拼接模板、采集、识别和批阅页面之间的关系。界面应围绕实际考试与阅卷操作组织，而不是直接展示内部技术模块。

具体信息架构与页面名称见第 3 节，尚未逐项定稿。

### 2.2 标题栏

- 删除右上角重复显示当前页面名称的“小标题”，对应当前 `TitleBarPageText`。
- 保留 NavigationView 与 TitleBar 的单窗口结构；业务操作不恢复为多个独立弹窗。
- 页面标题与上下文应在内容区表达，避免与导航选中项反复重复。
- LOGO 继续预留位置，不在本轮使用 `design.png`。

### 2.3 侧边栏与窗口布局

- 侧边栏展开时占用实际布局宽度，压缩主内容区，**不能覆盖内容**。
- 窄窗口与高 DPI 下仍须满足这一要求；内容区需重排，不能依靠遮挡内容解决空间不足。
- 当前 `LeftCompact` 展开时默认覆盖内容；仅切换到 `Auto` 不能保证窄窗口满足要求。
- 展开/收起的具体宽度、最小窗口尺寸和断点尚未确定。收起为图标栏、按钮换行、阅卷分栏改为上下布局是建议方案。

### 2.4 Mica

- Windows 窗口加入 Mica；标题栏、导航区与内容表面的背景需要协调，避免不透明背景完全遮住材质。
- Windows 10、不支持材质或关闭透明效果时使用正常主题底色；其他平台按现有平台边界适配。
- 答题纸预览、扫描图像和打印输出保持纸张内容的清晰背景，材质不进入打印内容。
- 实际显示、主题切换、回退与高 DPI 效果需要运行验证，不能仅以编译成功判定验收。

## 3. 已讨论但尚未逐项确认的 UX 建议

### 3.1 以考试组织操作

建议主线：

**创建考试 → 编排题目与答题纸 → 设置答案和评分规则 → 打印 → 扫描/导入答卷 → 复核与批阅 → 汇总成绩。**

- 同一考试共享题目结构、答题纸版本、答案键与评分规则，不要求每份学生答卷重复配置。
- 采集页面选择已生成的答题纸，不再重复填写一套题数、选项和主观题区域。
- 学生答卷统一展示身份确认、页面完整性、选择题待复核、主观题完成度和成绩确认状态。
- 未完成身份关联、复核或评分确认时，不将临时分数展示为正式最终成绩。
- “考试”用于组织本地工作资料，不据此扩展为完整学校管理系统。

### 3.2 导航与编辑器

| 层级 | 建议内容 |
| --- | --- |
| 主导航 | 考试、答题卡模板 |
| 考试内页面 | 概览、答题卡、答案与评分、学生答卷、阅卷、成绩 |
| 侧栏底部 | 设置、关于 |

建议将扫描与导入放在学生答卷页面；本地连接状态放入设置或异常提示。标题栏中的“本地服务”是否移除尚未最终确认。

生成页面建议采用“左侧题目结构、中间纸面预览、右侧所选项目属性”。正文输入先考虑文字与图片；Word/PDF 导入属于后续候选功能，不是本轮已确认交付项。

## 4. 已确认的答题纸内容模式

同时支持两种模式：

| 模式 | 学生用纸内容 |
| --- | --- |
| 独立答题卡 | 题号、题型分组、分值和答题区，不包含完整题目正文 |
| 包含正文的答题纸 | 题目正文及相应答题区，可包含题目图片 |

两种模式共用题号、题型、分值与答题区定义；是否输出正文决定纸面内容与排版。**标准答案和评分规则不输出到学生用纸。**

题目分组、填涂区、横线答题区、空白答题框与作文格是已讨论的设计方向，具体题型清单和各题型的编辑方式尚未全部定稿。

## 5. 已确认的纸张与分栏

- 仅设计 **A4 纵向（210 × 297 mm）** 和 **A3 横向（420 × 297 mm）**。
- 纸张由用户选择；此前讨论过的 A4 横向、A3 纵向不进入当前设计范围。
- A3 横向允许用户选择 **两栏或三栏**。
- 切换规格与栏数时重新排版，不能简单等比缩放文字和填涂框。
- A3 出现考生信息区时，该区域必须位于**第一栏顶部**，不能移到后续栏或横跨各栏。
- A4 草案将信息区放在页首。考试标题可以作为全页标题，不改变 A3 信息区的首栏位置。
- 是否启用双面及反面身份区由布局和扫描策略配合设置；具体打印设置界面尚未定稿。

## 6. 信息区、考试标识与考号

### 6.1 同一区域的内容

**考生信息、填涂示例和试卷机器识别码必须位于同一个信息/识别区。** A3 中该区固定在首栏。

姓名、班级、考号书写栏、教师填写的缺考标记是当前草案字段，是否必填、显示哪些字段及考号位数尚未确定。

四角定位标记和独立方向特征属于草案设计；具体形状、位置和实际识别可靠性需验证，不能与学生填涂混淆。

### 6.2 考试机器可读标识

- 答题纸必须带有可供机器识别所属考试的标识。
- 建议编码稳定的考试 ID、版式/模板版本、页码及正反面，以便找到对应布局和页面。
- 考试名称文本不能替代唯一考试标识；考试标识也不能替代考生身份标识。
- 具体码制（例如二维码）、编码协议、生成/读取库和版本校验规则尚未选定。
- 反面不重复考生身份区时，仍保留紧凑的考试/页面识别信息。

### 6.3 考号填写方式

- 考号支持 **条码或涂卡**，由用户选择；考号条码与考试机器识别码承担不同职责。
- 考号涂卡使用 0–9 数字；**数字位置与选择题字母共用“框内/框外”配置**。
- 框内时在每个填涂框内印对应数字或字母；框外时在对应框外显示，不以一列行首数字替代这一配置。
- 条码格式、来源、考号位数及有效范围待定。身份无法可靠确认时应进入复核，不能猜测考生。

## 7. 填涂框样式与尺寸

- 圆形框、矩形框可选。
- 字母/数字在框内或框外可选，配置规则一致。
- **圆形框直径、矩形框宽度均须为正值且 ≤2 mm。** 用户已将此前“严格小于 2 mm”修正为“小于等于 2 mm”。
- 2 mm 合法，超过 2 mm 的值不合法；存储、显示与打印尺寸应一致，避免舍入误导。
- 矩形高度、线宽、间距、字形和最终默认尺寸需实纸验证。预览的 1.8 mm 只是示例，预览控件范围不是产品最终限制。
- 框内印字属于印刷内容，识别时需考虑空白模板的印刷基线，不能直接把字母/数字笔画视为学生填涂。
- ≤2 mm 的各种组合需要打印、填涂与扫描验证，不能以屏幕预览宣称识别准确率已满足要求。

## 8. 解答题答题区与扫描框

- **扫描框宽度固定为所在栏可用宽度的 100%**，不提供比例宽度或缩窄宽度的配置。
- **高度按每一道题独立设置**，不是整张答题纸共享一个高度。
- 调整第 5 题只影响第 5 题，不改变第 6 题；同一题在两种内容模式下使用相同的区域设置。
- 高度采用纸面毫米表达。预览支持逐题输入，示例步长为 1 mm；最终范围、最小高度和是否支持小数精度尚未确定。
- 答题区高度改变时，排版与题图裁切几何同步更新，不能只有视觉框变化。
- 区域定义属于**生成答题纸阶段**。扫描和批阅复用所关联版本的区域，不要求阅卷者重新画框。
- 普通用户通过题目与空间设置完成操作，不需要手工填写 X/Y 坐标。

## 9. 反面身份区与扫描策略

用户已明确：**“反面填涂区可选”仅指反面的考号/考生身份区，不包括选择题作答填涂区。**

- 反面是否重复身份区由用户根据扫描策略选择；关闭该区不能删除题目填涂框。
- 若扫描流程可靠保留同一张纸的正反面关系，可利用该关系关联考生；具体配对规则待设计与验收。
- 对于打乱、分批或无法保证页序的采集，需要重复身份标识或人工关联，不能仅凭相同考试码归属于同一学生。
- 漏页、重复页、错序和无法确认归属的页面应明确进入待确认状态，不能静默配对。
- 没有反面身份区时保留紧凑信息/识别区，承载考试码和相应页面信息。

## 10. 分页、版本与验收建议

以下为配套设计建议，具体策略仍需确认：

- 按题组、正文与答题区进行分页；空间不足时换栏/换页，不意外拆散题号与对应区域。长题跨页策略待定。
- 已打印或已采集的答卷保留对应版式版本；后续编辑不能覆写历史答卷的几何定义。
- 使用实际毫米尺寸打印，不默认缩放适配纸张；A3 采集需匹配设备能力，不能宣称现有 A4 扫描路径已支持 A3。
- 继续保持本地/SDK 授权隔离，不因新增考试工作流扩大网页可访问的数据范围。
- OCR/AI 后续融入同一阅卷流程，并保留人工确认与修订入口；目前未选定提供方，也未引入 GLM-OCR 等依赖。

后续验收应覆盖：

- 两种内容模式、A4/A3、A3 两栏/三栏以及首栏信息区规则。
- 考试码与版式、页码、正反面的正确关联，考号条码与涂卡的身份确认。
- 圆形/矩形、字母/数字框内外、≤2 mm 尺寸的实纸识别与印刷基线处理。
- 逐题高度、100% 栏宽、自动排版与实际裁切图像的一致性。
- 双面配对及漏页、重复、错序、不明身份的处理。
- 实际打印比例、设备与纸张匹配、不同扫描分辨率和方向的样本测试。
- WinUI 启动、窄窗口、高 DPI、键盘操作、主题与 Mica 回退。

建议实施顺序为：明确数据与身份约定 → 生成与分页 → 编辑及阅卷界面 → 扫描与识别关联 → 实纸和界面验收。本文归档不自动启动上述实现。
